# Безопасность

## Что делает приложение

NowPlayingWidget — локальный виджет для Windows. Он:

- читает данные текущего трека через Windows Media Session (SMTC);
- рисует окно поверх рабочего стола;
- хранит настройки и лог только в профиле пользователя;
- **не открывает сетевые соединения, не отправляет телеметрию и не содержит
  рекламы или автообновления**.

Приложение не требует прав администратора. Автозапуск включается только по
желанию пользователя через `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

## Где хранятся данные

```
%APPDATA%\NowPlayingWidget\settings.json
%LOCALAPPDATA%\NowPlayingWidget\widget.log
%LOCALAPPDATA%\NowPlayingWidget\stock-covers.json
```

`stock-covers.json` содержит только хэши картинок, которые виджет распознал как
заглушки плееров. Никакие названия треков, история прослушивания или личные
данные туда не записываются.

## Проверка сборки

Официальные exe собираются публично в GitHub Actions из этого репозитория.
К каждому релизу прилагается `SHA256SUMS.txt` — сверьте хэш скачанного архива:

```powershell
Get-FileHash .\NowPlayingWidget-*.zip -Algorithm SHA256
```

Можно собрать exe самостоятельно:

```powershell
pip install -r requirements-dev.txt
.\build.ps1
```

## SmartScreen

Exe не подписан коммерческим сертификатом, поэтому Windows может показать
предупреждение SmartScreen. Это ожидаемо для небольших open-source проектов.
Если не хотите нажимать «Выполнить в любом случае», запускайте из исходников
или соберите exe сами — код полностью открыт.
